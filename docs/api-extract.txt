Общие сведения
1. 
Данный API работает в асинхронном режиме: сначала вы создаете задачу (Task), затем проверяете её статус и, когда она готова, скачиваете результат.
Ссылка на swagger: 
https://kandinskyapi.sberdevices.ru/docs
Общие параметры доступа
Base URL:

https://kandinskyapi.sberdevices.ru
<Токен авторизации> (передается в заголовке
)
Auth Token:


Authorization: Bearer ...

14.

GET
 
}/result

https://kandinskyapi.sberdevices.ru
/tasks/{task_id
